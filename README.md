# IOT-Home-Automation-ESP32
In this project I programmed an ESP32 to interface an LCD, three servo motors, four lamps through a 4 relay module.
I created a webpage by HTML and CSS and created buttons on it. The user can access these buttons by connecting to a router that the ESP32 is also connected to and entering the set address. The user presses the buttons on the webpage and can turn the lamps on and off and also rotate the servo motors. The entered input will be displayed on the LCD.
